# Balambika site

The presentation site for Balambika, published with GitHub Pages at
<https://nelvaron.github.io/balambika/>. Built with Astro 7 as a fully static
site in English (`/`) and Bulgarian (`/bg/`), styled with the nelvaron design
tokens in a light and a dark theme.

## Develop

```sh
cd site
npm install
npm run dev      # http://localhost:4321/balambika/
npm run build    # static output in dist/
npm run preview
```

`npm run dev` and `npm run build` first run `scripts/build-fonts.mjs`, which
reads the release fonts in `../fonts/ttf/` and generates:

- `public/fonts/*.woff2`: lossless WOFF2, all glyphs and OpenType features kept;
- `src/data/generated/glyphs.json`: the character inventory shown on the
  specimen pages, read from the font's cmap;
- `public/favicon.svg` and the PNG app icons, drawn from the real outlines of
  “बा”;
- `public/og.png`: the Open Graph image, from `../images/social-banner.png`.

These files are not committed. When the fonts change, rebuild and the site
follows.

`src/data/conjuncts.json` is committed. It records how many glyphs each
conjunct shapes to at every stage of the “Shaping, step by step” control and
is produced with HarfBuzz:

```sh
pip install uharfbuzz
python3 site/scripts/shape-data.py
```

Re-run it after a change to the Devanagari.

## Structure

| Path | Contents |
|---|---|
| `src/pages/[...locale]/` | Overview, specimens, usage and privacy, generated for both locales |
| `src/components/` | Hero and glyph globe, verse ledger, conjunct explorer, Vedic accents, type tester, passages, downloads |
| `src/scripts/globe.ts` | The animated globe (Canvas 2D, no dependencies) |
| `src/data/` | Source passages and translations, specimen texts, shaping stages |
| `src/i18n/ui.ts` | Interface strings, locale paths and plural rules |
| `src/styles/tokens.css` | nelvaron tokens as `light-dark()` pairs |

Source passages live in `src/data/texts.ts`. Devanagari and IAST follow
standard editions; the English and Bulgarian translations are the project's
own. Use U+02BC for avagraha in IAST.

## Platform features used

Cross-document view transitions, `light-dark()` and `color-scheme`, `:has()`
for the shaping stages, the Vedic accent switch and the type tester, container
queries, scroll-driven reveal animations, CSS scroll markers on the passage
carousel, the Popover API with CSS anchor positioning, `field-sizing`,
`text-wrap: balance | pretty`, and `font-feature-settings` to step through
Devanagari shaping. Every one of them degrades to a working page where it is
not supported.

## Web platform checklist

The site follows the required and recommended items of
[specification.website](https://specification.website) where GitHub Pages
allows it:

- One `<h1>` per page, landmarks, a skip link, visible focus, 44 px targets,
  `lang` on every passage (`sa`, `sa-Latn`, `bg`, `en`), reduced motion and a
  pause control for the globe, forced-colours support.
- Canonical URLs, reciprocal `hreflang` with `x-default`, localised titles and
  descriptions, Open Graph, JSON-LD (`WebSite`, `SoftwareApplication`,
  `BreadcrumbList`), an XML sitemap, `llms.txt` advertised with
  `rel="describedby"`, a web app manifest, SVG and PNG icons, `theme-color`
  for both schemes.
- A Content Security Policy in a `<meta>` tag with SHA-256 hashes for every
  inline script, generated by Astro; no third-party requests; a privacy page;
  no cookies.
- A custom 404 page.

Not possible on GitHub Pages, because it cannot set response headers or serve
files at the host root for a project site: HSTS preload settings,
`frame-ancestors`, `Permissions-Policy`, `Referrer-Policy` as a header (a
`<meta name="referrer">` is used instead), `Link` headers, and `robots.txt` or
`/.well-known/security.txt` at `nelvaron.github.io/`. A custom domain in front
of a CDN would make them possible.

## Deploy

`.github/workflows/pages.yml` builds and deploys on every push to `main` that
touches `site/`, `fonts/ttf/` or `images/`. In the repository settings, set
*Pages › Build and deployment › Source* to **GitHub Actions** once.
